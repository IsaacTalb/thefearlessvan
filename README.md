# The Fearless Van

Phase 1 of the official digital home for Joshua "The Fearless" Van.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Custom CSS design system

## Local development

```bash
npm install
npm run dev
```

Use `npm run build` for a production build and `npm run lint` for linting.

Fighter stats and timeline content live in `app/data.ts`. Phase 1 intentionally uses a graphic-led direction without unlicensed fighter photography. Team-approved assets can replace the prepared hero and media treatments in Phase 2.
