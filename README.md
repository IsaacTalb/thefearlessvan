# The Fearless Van

Phase 1–3 of the digital home for Joshua "The Fearless" Van.

## Stack

- Next.js 16 (App Router)
- React 19
- TypeScript
- Custom CSS design system

## Local development

```bash
npm install
npm run dev
```

Use `npm run build` for a production build and `npm run lint` for linting.

Fighter stats, selected fight data, and timeline content live in `app/data.ts`.

## Routes

- `/` — campaign homepage
- `/story` — athlete journey
- `/fights` — selected fight archive
- `/media` — editorial media archive
- `/partners` — partnership opportunities
- `/contact` — enquiry routing

The project includes route metadata, JSON-LD, sitemap, robots, web manifest, generated Open Graph artwork, app icon, and branded 404.

Replace the graphic media placeholders with team-approved assets, confirm every stat against the official record, replace `team@thefearlessvan.com`, and add official social URLs.
